# CTF Crypto Practice

CTF Cryptoの学習記録と練習コードを公開しています。
Pythonの練習コードをまとめています。

## Learning

This repository is part of my CTF learning.

## Contents

このリポジトリには、主に以下のような暗号・エンコードに関する
練習コードを置いています。

- Base64
- XOR
- Vigenere Cipher
- RSA
- UTF-8 (encode/decode)
- Hash

## Files

| File | Description |
|---|---|
| `base64_practice.py` | Base64のエンコード・デコード練習 |
| `XOR.py` | XORを使った暗号・復号の練習 |
| `Vigenere cipher.py` | Vigenere暗号の練習 |
| `RSA.py` | RSA暗号の練習 |
| `UTF-8_encode.py` | UTF-8に関する練習 |
| `hash_encode.py` | ハッシュ関数の練習 |
